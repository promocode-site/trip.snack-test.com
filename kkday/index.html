KKday 할인코드 입력 방법

접속부터 결제 완료까지 다섯 단계입니다. 정액 할인코드는 첫 단계를 건너뛰면 적용되지 않습니다.

  1. 1

    제휴 링크로 KKday 접속

    할인코드 발급 버튼으로 KKday를 연 다음, 같은 창에서 로그인합니다. 신규 회원 할인코드를 쓸 계획이면 여기서 가입하고 앱으로 이어서 엽니다.

  2. 2

    상품·날짜·인원 확정

    옵션과 인원을 모두 고른 뒤의 금액이 할인코드 선택 기준입니다. 400,000원 근처라면 인원·옵션 조정으로 정액 3만원 구간에 들어가는지 먼저 확인합니다.

  3. 3

    결제 화면 프로모션 코드 칸에 입력

    예약자 정보를 채운 결제 화면에서 프로모션 코드 칸에 할인코드를 넣고 적용을 누릅니다. 대문자와 숫자를 그대로 붙여 넣습니다.

  4. 4

    할인 금액 줄 확인

    결제 요약에 할인 금액이 따로 찍혔는지 봅니다. 정률 할인코드는 한도에서 멈춘 금액이 표시되므로 계산과 다르면 한도에 걸린 것입니다.

  5. 5

    결제 후 바우처 확인

    결제가 끝나면 주문 내역에서 할인 적용 금액과 바우처 발급 상태를 확인합니다.
