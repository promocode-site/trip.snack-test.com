나이키 프로모션코드 직접 입력 순서

  1. 1

    멤버 로그인

    대학생 쿠폰은 비회원 주문에서 쓸 수 없으니 인증할 때 쓴 계정으로 로그인하세요.

  2. 2

    제품 페이지에서 쿠폰 적용 불가 문구 확인

    SNKRS 제품이나 쿠폰 적용 불가로 표시된 제품은 장바구니에 담기 전에 걸러 두세요.

  3. 3

    결제 단계의 프로모션 코드 칸 열기

    주문 단계 화면에서 프로모션 코드 입력란을 눌러 할인코드 또는 이메일로 받은 쿠폰 코드를 그대로 넣습니다.

  4. 4

    주문 요약의 할인 금액 확인

    할인 줄이 생기지 않으면 할인코드가 만료됐거나 대상 제품이 아닙니다. 할인 금액을 주문 금액으로 나눠 실제 할인율도 확인하세요.

자동 적용 나이키 쿠폰 확인 순서

  1. 1

    프로필의 멤버 리워드 열기

    웰컴 쿠폰과 생일 쿠폰이 계정에 생성됐는지 먼저 확인합니다. 생일 쿠폰은 발급 문자를 받은 뒤 확인하면 빠릅니다.

  2. 2

    웰컴 쿠폰은 앱에서 장바구니 담기

    웹 장바구니에서 결제하면 웰컴 쿠폰이 붙지 않으니 나이키 앱으로 옮겨 주문하세요.

  3. 3

    적용된 쿠폰 이름과 금액 점검

    결제 전에 어떤 쿠폰이 적용됐는지 확인하고, 상한 금액을 넘는 주문이면 장바구니를 나눌지 판단하세요.

받을 수 없습니다. 웰컴·생일·대학생 쿠폰은 모두 나이키 멤버 계정에 연결되므로 가입 후 로그인한 상태로 주문해야 합니다.
