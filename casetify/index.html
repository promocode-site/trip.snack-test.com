입력 방법

케이스티파이 할인코드 입력 방법

결제 화면의 한 칸에만 입력하면 됩니다.

  1. 1

    전용 링크로 접속하고 로그인

    할인코드 발급 버튼으로 케이스티파이에 접속합니다. KAKAO15를 쓸 계획이라면 카카오톡 채널을 먼저 추가하고 로그인하세요.

  2. 2

    기종과 상품 선택

    기종과 케이스를 고른 뒤 Co-Lab 표시가 있는 상품인지 확인합니다. Co-Lab 상품은 할인코드 대상에서 빠집니다.

  3. 3

    장바구니에서 합계 확인

    자동 할인이 이미 붙었는지 확인하고 할인코드 입력 전 합계를 기록해 둡니다.

  4. 4

    결제 화면에서 할인코드 입력

    '바우처, 프로모션 코드, 기프트 카드 사용하기' 칸에 할인코드를 입력하고 적용합니다. 대문자 그대로 붙여 넣으면 오타를 줄일 수 있습니다.

  5. 5

    할인 금액 확인 후 결제

    합계가 줄었는지 확인합니다. 줄지 않았다면 다른 할인코드로 바꿔 입력하고, 최종 금액이 맞으면 결제하세요.

케이스티파이 할인코드는 콜라보 상품에도 적용되나요? +
적용되지 않습니다. 확인된 6개 할인코드 모두 Co-Lab 제품은 제외됩니다. 일반 상품과 함께 담으면 일반 상품 금액에만 할인이 붙습니다.
할인코드를 두 개 이상 함께 쓸 수 있나요? +
한 주문에 할인코드 1개만 사용할 수 있습니다. 여러 개를 넣고 싶다면 주문을 나눠야 하지만, 나눈 주문마다 배송 조건이 달라질 수 있어 합계를 먼저 비교하세요.
KAKAO15를 입력했는데 적용되지 않으면 어떻게 하나요? +
카카오톡 채널 추가와 로그인 상태를 다시 확인하세요. 그래도 적용되지 않는 사례가 보고되어 있고 선착순으로 소진될 수 있으니, 이때는 SIERRA15 같은 15% 할인코드로 바꿔 입력하세요.
JESS 할인코드가 최신 아이폰 케이스에 안 되는 이유는 무엇인가요? +
최신 기종 케이스는 자동 제외 대상이기 때문입니다. 이 경우 15% 전 상품 할인코드를 쓰는 편이 낫습니다.
최소 주문 금액이 있나요? +
확인된 출처에는 최소 주문 금액이 표기되어 있지 않습니다. 최대 할인액도 표기가 없으므로 결제 화면에서 실제 할인 금액을 확인하세요.
할인코드의 사용 기간은 언제까지인가요? +
6개 모두 기간이 표기되어 있지 않습니다. 언제든 종료되거나 소진될 수 있어 사용 전에 입력 결과를 확인해야 합니다.
